# MerchFlow AI

### An AI-Powered Prompt Library for Apparel Merchandising and Production Coordination

**Subject:** BUS4005 – Artificial Intelligence for Business  
**Assessment:** Assessment 1  
**Institution:** La Trobe University

## Project Overview

MerchFlow AI is a structured library of ten interconnected AI prompts designed to improve apparel merchandising, production coordination, operational reporting and management decision-making.

The project uses a hypothetical Bangladeshi garment manufacturer, Meridian Apparels Ltd., and synthetic business data to demonstrate practical applications of generative AI.

## Iterative Testing Methodology

1. Initial prompt development (Version 1).
2. Testing using Claude AI.
3. Critical evaluation of generated outputs.
4. Prompt refinement (Version 2).
5. Retesting and comparative evaluation.
6. Final prompt selection.

## Repository Contents

Each prompt folder will contain:

- Version 1 prompt
- Version 1 Claude output
- Version 2 prompt
- Version 2 Claude output
- Iterative evaluation and improvement justification

## Business Objectives

- Reduce repetitive administrative workload.
- Improve operational reporting accuracy.
- Strengthen buyer and supplier communication.
- Identify production and delivery risks.
- Support evidence-based management decisions.
- Maintain confidentiality and human oversight.

## Responsible AI and Limitations

All business scenarios and operational data are synthetic. AI-generated recommendations require human verification and authorisation.

The system does not independently approve production, determine quality acceptance or make commercial commitments.

The anticipated business benefits have not been validated through real-world implementation.

## AI Tools Used

- **ChatGPT:** Prompt development, evaluation and refinement.
- **Claude:** Prompt testing and output generation.
- **GitHub:** Documentation and testing portfolio.
